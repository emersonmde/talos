# Roadmap Process

The roadmap should stay current throughout the project. A stale roadmap is a process bug.

Each milestone needs:

- A user-visible capability.
- Acceptance criteria.
- Enough prerequisites, verification notes, known risks, and documentation requirements to make the work executable.

The top-level roadmap may keep those details concise. Before implementation starts for a milestone, expand them in the milestone task record or a focused design note:

- Prerequisites.
- Verification method.
- Known risks.
- Required documentation updates.

Milestones should be revisited whenever hardware findings, failed assumptions, or new lab capabilities change the project shape.
