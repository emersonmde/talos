# Talos

Talos is a new Raspberry Pi 5 bare-metal operating system project.

It exists because DaedalusOS was built around the Raspberry Pi 4 development loop. Talos starts from a different premise: use an automated physical lab to make real hardware iteration fast enough for long-running agent-assisted kernel development.

The project is currently in planning. The first deliverables are documentation, roadmaps, task structure, hardware lab contracts, and architecture decisions.
