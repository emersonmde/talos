# Phase 12.6 SSH KEXINIT negotiation core

Task id: phase12-ssh-kexinit-negotiation-core-20260622

Status: accepted.

Classification: phase12-ssh-kexinit-negotiation-core-accepted.

## Goal

Implement the accepted local modeled SSH KEXINIT/algorithm-negotiation
contract while keeping ssh-ready false and rejecting actual key exchange,
encryption, authentication, session, shell, hardware reachability,
compatibility, broad expansion, and phase transition.

## Scope

- Add the smallest Talos-owned SSH binary packet/KEXINIT model required by the
  accepted contract.
- Compose it with the accepted local listener/transport and CSPRNG boundary so
  the modeled connection can classify one KEXINIT negotiation step without
  retaining random cookie bytes or secrets.
- Cover positive and negative algorithm-list/client-input cases with focused
  source/unit tests and redaction review.

## Non-goals

- No actual ECDH/key exchange, shared secret computation, encryption/MAC
  enablement, NEWKEYS, host-key signing, authentication success,
  session/channel execution, PTY allocation, shell attachment, hardware/lab
  action, boot publication, hardware reachability, OpenSSH/POSIX/Linux
  compatibility claim, broad socket expansion, broad SSH service expansion,
  stale link-ready discriminator work, broad expansion, or phase transition.
- No generated random bytes, KEX cookie bytes, private host-key bytes,
  authorized-key bytes, shared secrets, fingerprints, digests, peer addresses,
  peer identification text, operator identity, key-derived identifiers, stable
  transport/session identifiers, client packet bytes, or client algorithm-list
  text retained in diagnostics or evidence.

## Implementation

- Extended sshservicediag readiness labels for the accepted KEXINIT contract:
  kexinit-modeled, cookie-generated-redacted, client-packet-valid,
  algorithm-negotiated, algorithm-unsupported, packet-malformed,
  packet-over-limit, list-over-limit, first-packet-follows-ignored, and fixed
  selected-policy labels.
- Added a bounded SSH_MSG_KEXINIT parser/model after the accepted local
  listener/transport and remote-identification path. It enforces:
  - packet_length <= 1024 bytes;
  - payload <= 768 bytes;
  - name-list <= 256 bytes;
  - at most 16 names per list;
  - SSH_MSG_KEXINIT message number 20;
  - 16-byte client cookie shape with no retained bytes;
  - fail-closed malformed, oversized, list-limit, and unsupported-algorithm
    classifications.
- Added fixed reversible policy matching for curve25519-sha256, ssh-ed25519,
  chacha20-poly1305@openssh.com in both directions, hmac-sha2-256 in both
  directions, compression none in both directions, and empty language lists.
- Used the accepted operator-seeded CSPRNG boundary to generate a modeled
  server KEXINIT cookie and immediately zeroize it. Diagnostics record only the
  cookie-generated-redacted label.
- Preserved existing disabled and prerequisite-missing service states; they do
  not model KEXINIT and still keep listener/transport counters at zero.
- Updated Phase 12 SSH docs and the roadmap with the accepted local modeled
  KEXINIT frontier and selected next smoke task.
