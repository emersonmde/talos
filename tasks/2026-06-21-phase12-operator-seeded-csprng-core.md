# Phase 12.5 operator-seeded CSPRNG core

Task id: phase12-operator-seeded-csprng-core-20260621

Status: accepted.

Classification: phase12-operator-seeded-csprng-core-accepted

## Goal

Implement the smallest no_std operator-seeded CSPRNG core and diagnostic
readiness mapping selected by the accepted secret-material and dependency
contracts.

## Scope

- Added the selected dependencies:
  chacha20 0.10.0 with default-features=false and features rng,zeroize, plus
  zeroize 1.8.1 with default-features=false.
- Added a Talos-owned csprng module that privately wraps
  chacha20::ChaCha20Rng.
- Added fail-closed readiness states for missing, invalid, insufficient,
  conditioning-failed, and ready seed inputs.
- Added bounded output through caller-provided buffers only after ready state.
- Extended entropy/sshkeydiag readiness metadata so an internal CSPRNG-ready
  report can set cryptographic-strength true while ssh-ready remains false.
- Added focused source/unit tests using public fixture seed material without
  retained generated byte streams.

## Findings

- fixed: the implementation compiles no_std with the selected chacha20 and
  zeroize dependency/features.
- fixed: raw seed bytes are consumed only inside src/csprng.rs through the
  accepted /etc/talos/operator-seed.bin boundary or public unit fixtures.
- fixed: missing, invalid, zero-length, oversized, and insufficient seed inputs
  fail closed and do not return partial output.
- fixed: sufficient 32 through 4096 byte input initializes a private
  ChaCha20Rng after Talos-owned bounded conditioning.
- fixed: the diagnostic model can represent cryptographic-strength true only
  from CSPRNG-ready metadata; ssh-ready remains false.
- fixed: source tests avoid retaining real operator secrets, generated byte
  streams, digests, fingerprints, RNG state, serialized state, stream
  identifiers, or comparable secret identifiers in task evidence.
- deferred: retained shell/internal smoke evidence belongs to
  phase12-shell-csprng-readiness-smoke-20260621.
- deferred: host-key generation/provisioning, authorized-key storage, writable
  seed persistence, SSH service behavior, live transport, hardware
  reachability, public ABI/POSIX/Linux compatibility, broad expansion, stale
  link-ready discriminator work, and phase transition.
- not-an-issue: no Pi 5 hardware run or boot archive publication is required
  for this source/unit CSPRNG core task.
