## Diagnostic Shape

The entropy command now emits:

~~~text
diag: ok entropy
diag: entropy-label <entropydiag-label>
diag: hardware-rng entropydiag-hardware-rng-unaccepted
diag: operator-seed entropydiag-operator-seed-required
diag: csprng-readiness <csprng-label>
diag: cryptographic-strength <bool>
diag: ssh-ready false
~~~

The operator-seed line remains optional and is omitted once selected seed
metadata is present. The CSPRNG readiness line is fixed-label metadata only; it
does not expose seed bytes, generated bytes, fingerprints, digests, signatures,
session identifiers, or stable secret-derived identifiers.
